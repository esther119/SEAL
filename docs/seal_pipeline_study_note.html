Compute one vector

Correctness is no longer used in the subtraction.

vector = mean(check + switch) - mean(other)

Why correct and incorrect are separated, then combined

The split is a sampling control, not the final contrast. The code first creates two balanced trace pools: 500 successful reasoning traces and 500 failed reasoning traces. It then combines both pools when building the vector.

Final contrast: steering vector = mean(reflection/check + transition/switch states) - mean(other states)

Why not 1000 correct?

  • Correct traces can still overthink.
  • Incorrect traces can contain useful reflection signals.
  • Correct-only may learn “successful solution style.”
  • Balanced sampling reduces outcome bias.
