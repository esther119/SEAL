A visual walkthrough of load_labeled_boundary_states. This function loads one hidden.pt, selects one model layer, then separates its boundary hidden states into check, switch, and execution piles. The example below explains every data structure it touches, especially layer_data. It is a supporting implementation note for the S_general vector.

The core idea

layer_data
  ├── trace 0: 4 boundary rows
  ├── trace 1: 2 boundary rows
  └── trace 2: 0 boundary rows
          │
          ▼ load_labeled_boundary_states(...)
  check pile + switch pile + execution pile
layer_data has no overall shape because traces contain different numbers of boundaries. Each individual boundary_hidden_states tensor does have shape [number_of_boundaries, hidden_dimension].
